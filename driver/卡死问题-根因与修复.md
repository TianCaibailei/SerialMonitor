# 卡死问题：根因与修复步骤

> 2026-11-11 · 已定位并修复，需管理员停驱动后重新部署

## 一、你遇到的卡死是怎么回事

`verify-driver.ps1` 走到第 3 步没有输出，PowerShell 无法退出。

### 根因：加载了**旧版驱动**

| 文件 | 大小 | 说明 |
|---|---|---|
| `umserialfilter_x64.sys` | **21,504 字节** | 新版，含会话密钥认证 |
| `umserialfilter.sys` | **17,288 字节** | **旧版，被实际加载** |

我上一轮把构建脚本改成多架构，输出名变成了 `umserialfilter_x64.sys`，
但 `setup-driver.ps1` 加载的仍是 `umserialfilter.sys` —— **旧文件没被更新**。

于是：

```
新版 reader → 发 IOCTL_AUTHENTICATE 握手
旧版驱动   → 不认识这个 IOCTL（编号 0x805），走默认分支
           → reader 等待响应，永久阻塞
           → 进程卡在内核态，连任务管理器都杀不掉
```

### 为什么之前没发现

`Copy-Item` 覆盖 `umserialfilter.sys` 时，**旧驱动正在运行并占用该文件**，
复制**静默失败**（没有报错），脚本以为成功了。

## 二、已修复的内容

### 1. 构建脚本会同步文件名 + 覆盖失败时明确报错

```
PASS umserialfilter_x64.sys (21,504 字节)
警告: 无法覆盖 umserialfilter.sys
  （文件可能被已加载的驱动占用 —— 先 sc stop UmSerialFilter）
```

现在这类问题会当场暴露，不会静默部署错版本。

### 2. reader 快速失败

- 新增 `IOCTL_AUTHENTICATE` 握手，失败立即退出并提示原因
- 修掉一个真实 bug：原来把**同一个变量**同时当输出缓冲和 `lpBytesReturned`（别名 UB），
  且驱动拒绝时会拿旧值继续往下跑
- `GET_RECORD` 缓冲不足自动扩容

### 3. verify-driver.ps1 全面加超时

所有子进程用 `Start-Process` + `WaitForExit(毫秒)`，超时强制 Kill 并报告：

```
（超时 25s，强制结束进程 PID 12345）
  FAIL: reader 超时未返回 —— 驱动拒绝了 IOCTL 且没有快速失败
  最可能的原因：加载的是不含认证逻辑的旧驱动
  检查驱动文件大小（当前版本应为约 21,504 字节）
```

不会再出现"脚本看起来冻结"的情况。

## 三、现在请你执行（需要管理员）

### 第 1 步：停止并删除旧驱动

**管理员 PowerShell**：

```powershell
sc stop UmSerialFilter
sc delete UmSerialFilter
```

如果 `sc stop` 卡住或报错，**重启电脑**最干净。

### 第 2 步：确认卡死的进程已消失

```powershell
Get-Process umfilter_reader -ErrorAction SilentlyContinue
```

有残留就结束它（停驱动后应该就能杀了）。

### 第 3 步：重新编译并部署

```powershell
cd E:\Documents\MonitorAnything\MonitorAnything\driver

# 一键重建（会自动同步 umserialfilter.sys 并签名）
powershell -ExecutionPolicy Bypass -File rebuild-all.ps1
```

**注意输出**：必须看到
```
PASS umserialfilter_x64.sys (21,504 字节)
      已同步为 umserialfilter.sys          ← 不能是"警告: 无法覆盖"
```

如果还是"警告: 无法覆盖"，说明驱动没停干净，回到第 1 步。

### 第 4 步：安装并验证

```powershell
powershell -ExecutionPolicy Bypass -File setup-driver.ps1
powershell -ExecutionPolicy Bypass -File verify-driver.ps1
```

## 五、如果第 3 步还卡

现在会超时并告诉你原因，把输出发我。可能情况：

| 现象 | 含义 | 处理 |
|---|---|---|
| 超时 + 提示文件大小是 17,288 | 还是旧驱动 | 驱动没停干净，重启再试 |
| `认证失败 (err=5)` | 密钥不匹配 | 检查 `HKLM\Software\UmSerialFilter\SessionKey` 是否存在 |
| `无法从 HKLM 读取会话密钥` | 驱动没写注册表 | 驱动是旧版，或权限问题 |
| `附加到 0 个` | 驱动启动但没找到串口 | 端口名不在识别列表，告诉我设备管理器里的名字 |
