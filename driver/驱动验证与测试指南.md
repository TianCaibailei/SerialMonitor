## 四、已实现的关键能力

### 1. 端口自动发现（对齐参考驱动）

参考驱动 `ComDrv12x64.sys` 用 `ZwOpenDirectoryObject("\Device")` 遍历设备目录。
我们的驱动用等价的文档化 API `ZwQueryDirectoryObject`，按 16 类名称片段识别：

```
Serial / USBSER / ComPort / Prolific / Silabser / VSerial / VCP
/ FTDI / BthModem / ttyS / ttyUSB / cdc_acm / Ch341 / MCT_U232 / ComDB
```

覆盖：主板原生串口、USB 转串口（FTDI/Prolific/CP210x/CH340）、
虚拟串口（ELTIMA/com0com）、蓝牙串口。

### 2. 热插拔

`IoRegisterPlugPlayNotification(GUID_DEVINTERFACE_COMPORT)` 监听设备到达，
新插入的 USB 串口会**自动附加**，无需重启或手动扫描。

### 3. 不占用端口

驱动是**上层设备过滤驱动**：`IoAttachDeviceToDeviceStack` 挂到设备栈，
只在 `IRP_MJ_READ/WRITE` 完成后复制数据，**从不打开端口**。
业务程序照常独占使用。
