## P0：可靠性缺口（建议优先）

### 1. Table 视图只渲染最后 2 万行，且用户无感知

**现状**：`view_table` 渲染 `vis[len-20000..]`，更早的行既不显示也不提示。
查找命中落在窗口外时，`scroll_to_row` 也无法定位（行根本不在渲染集合里）。

**为什么值得做**：这是"数据明明抓到了却找不到"的典型体验断裂；对一个靠"事后查证"
产生价值的监视器，检索不可靠会直接削弱核心用途。

**做法**：滚动到顶部时按需向前加载（分页/游标），或改用虚拟滚动 + 全量索引；
至少显示「仅显示最近 20000 行，共 N 行，更早的请导出」。

**代价**：中。涉及表格数据源改造。**验收**：10 万行会话中查找第 1 行能定位到。

### 2. 会话内 `unwrap()` 仍有 12 处

**现状**（实测）：`session.rs` 非测试代码区有 12 处 `unwrap()`，例如
`bufs.get(&idx).unwrap()`、`udp_socks[idx].clone().unwrap()`。
这些索引由内部逻辑保证存在，但一旦重构破坏该假设就是 panic（GUI 直接崩）。

**做法**：把 `bufs.get_mut(&idx).unwrap()` 换成 `entry` API 或提前 `let Some(..) else`；
`udp_socks[idx]` 换成 `get(idx).and_then(|o| o.as_ref())`。

**代价**：低（机械替换 + 现有测试保护）。**验收**：`rg '\.unwrap\(\)' src/session.rs` 在非测试区为 0。

### 3. 全局 Mutex 中毒即 panic

**现状**：`tcp_conns.lock().unwrap()`。技术手册的"五条不变量"第 4 条要求
「Mutex 中毒必须恢复不能 unwrap」，hook DLL 侧遵守了，主程序侧没有。

**做法**：封装 `fn lock_or_recover<T>(m: &Mutex<T>) -> MutexGuard<T>`（中毒时
`into_inner()` 继续），替换全部 `.lock().unwrap()`。

**代价**：低。**验收**：新增一个故意让持锁线程 panic 的测试，确认后续访问不崩。

## P1：可用性与信息完整性

### 4. 「打开会话」只能开最近一个

**现状**：没有原生文件对话框（依赖集里没有 `rfd`），`open_archive_recent` 只开
`recent_archives[0]`，且列表来自 `config.ini`。

**做法**：加 `rfd` 依赖（纯 Rust，Windows 上用 IFileDialog），提供真正的
打开/另存为对话框 + 最近文件子菜单（可选任一项）。

**代价**：低（一个依赖 + 一个菜单）。**验收**：能打开任意路径的 `.umses`。

### 5. 导出/复制缺少"范围选择"

**现状**：只有「全部」和一个选中行。没有多选、时间范围、通道范围。

**做法**：Ctrl+点击多选（`selected: Option<usize>` → `HashSet<usize>`），
导出时提供「选中 / 当前过滤结果 / 全部」三选一。

**代价**：中。**验收**：选中 3 行导出，文件里恰好 3 行。

### 6. 无实时告警/触发

**现状**：只能人盯着看。没有"匹配到 X 就提示"。

**做法**：过滤条件上加「命中时 toast / 声音 / 托盘通知」；进一步可做"命中即自动导出"。

**代价**：中。**验收**：配置关键字后，串口出现该内容即弹提示。

### 7. 高 DPI / 主题 / 字体设置缺失

**现状**：字体从系统固定几个路径加载，无字号/主题/缩放选项。

**做法**：egui 内置 `Context::set_pixels_per_point` 与 theme；暴露"界面缩放 / 明暗 / 字号"。

**代价**：低。**验收**：200% 缩放下布局不重叠。

## P2：技术债

### 8. egui 0.28 → 新版本

**现状**：`eframe/egui/egui_extras/egui_plot` 均为 0.28.1，已是较旧版本。

**为什么暂时不做**：API 变动较大（0.29+ 改了 `Rounding`/`Frame` 等类型），
收益主要是新控件与性能，而当前 UI 功能不受阻。

**做法**：单独一个分支升级，跑完 `check-all.ps1` 与截图对比再合并。

**代价**：中高。**验收**：功能等价 + 截图对比无回归。

### 9. 诊断探针（`app/tests/*.rs`）与生产代码混在一起

**现状**（实测）：12 个探针是 `fn main()` 程序，被 cargo 当作集成测试编译；
`cargo test --workspace --all-targets` 里有 **14 个测试二进制各跑 0 个测试**。

**做法**：移到 `tools/probes/`（独立 crate 或 `[[bin]]`），或标注 `#![cfg(never)]`。

**代价**：低。**验收**：`cargo test` 输出中不再出现空测试二进制。

### 10. 硬编码绝对路径

**现状**：`docs` 与 `driver/*.ps1` 里仍有 `E:\Documents\MonitorAnything\...`、`E:\tools\wdk-nuget\`。

**做法**：脚本里改用 `$PSScriptRoot` 推导，WDK 路径走参数或环境变量。

**代价**：低。**验收**：把仓库克隆到另一个盘符，`check-all.ps1` 仍全绿。

## P3：能力扩展（锦上添花）

- **自定义协议解析插件**：当前只有 Modbus。可做"按正则/偏移提取字段"的轻量规则引擎。
- **定时/条件录制**：按时间或触发条件自动开始/停止采集并落盘。
- **会话对比**：两个会话并排 diff（找"正常 vs 异常"那次通信的差异）。
- **寄存器值解释**：Modbus Values 支持 float/有符号/字节序切换。
- **多语言 UI**：目前全中文。
