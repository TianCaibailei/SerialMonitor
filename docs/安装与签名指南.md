## 二、驱动做了什么

| 项 | 说明 |
|---|---|
| 类型 | **上层设备过滤驱动**（upper filter） |
| 挂接方式 | `IoAttachDeviceToDeviceStack` 挂到串口设备栈 |
| 端口占用 | **完全不占用**，业务程序照常独占使用 |
| 拦截内容 | `IRP_MJ_READ` / `IRP_MJ_WRITE` 完成后的数据副本 |
| 数据通道 | 控制设备 `\\.\UmSerialFilter` + IOCTL |
| 覆盖范围 | 所有进程（可按 PID 过滤） |

这与你参考的 CommMonitor 驱动原理一致 —— 它也是
`IoGetDeviceObjectPointer` + `IoAttachDeviceToDeviceStack` + 完成例程。

## 三、⚠️ 需要你执行的步骤（必须管理员 + 重启）

### 步骤 1：开启测试签名

以**管理员身份**打开 PowerShell（右键"以管理员身份运行"），执行：

```powershell
bcdedit /set testsigning on
```

确认已设置：

```powershell
bcdedit /enum {current} | Select-String testsigning
```
应看到 `testsigning             Yes`

### 步骤 2：导入测试证书到信任区

**同一个管理员 PowerShell** 中：

```powershell
$cert = "E:\Documents\MonitorAnything\MonitorAnything\driver\umfilter-test.cer"

# 导入到"受信任的根证书颁发机构"
Import-Certificate -FilePath $cert -CertStoreLocation Cert:\LocalMachine\Root

# 导入到"受信任的发布者"
Import-Certificate -FilePath $cert -CertStoreLocation Cert:\LocalMachine\TrustedPublisher
```

> 如果系统提示安全警告，选择"是"。

### 步骤 3：重启电脑

**必须重启**，`testsigning` 才会生效。

重启后验证：

```powershell
bcdedit /enum {current} | Select-String testsigning
```
应显示 `testsigning             Yes`

## 五、当前驱动的能力与限制

### 已实现

- ✅ 挂接到串口设备栈，不占用端口
- ✅ 拦截读写数据（完成例程中复制，不改变原 IRP）
- ✅ 记录 PID、方向、时间戳
- ✅ 队列有界（512 条），满了丢最旧
- ✅ 支持按 PID 过滤

### 已知限制

1. **设备名列表是静态的**
   当前硬编码了常见串口设备名（`\Device\Serial0-9`、`\Device\USBSER000` 等）。
   如果你的虚拟串口用的是其他名字（例如 `\Device\VSerial8_2`），
   已在列表里；若没有，需要补充候选名后重新编译。

2. **需要重新附加新插入的设备**
   热插拔新串口后，需要再次调用 `IOCTL_UM_ATTACH_PORTS`（reader 程序启动时会自动调用）。

3. **未做 IOCTL/波特率等控制类 IRP 的捕获**
   当前只抓 READ/WRITE 数据流。若要抓波特率设置等，需要额外处理 `IRP_MJ_DEVICE_CONTROL`。

## 七、后续：集成到软件安装包（你提到的目标）

要让用户"无感"使用，安装包需要：

1. **检测驱动是否已安装/运行**
   ```powershell
   sc query UmSerialFilter
   ```

2. **安装驱动服务**
   ```powershell
   sc create UmSerialFilter type= kernel binPath= "<安装目录>\umserialfilter.sys"
   sc start UmSerialFilter
   ```

3. **签名问题**（生产环境必备）
   - 开发测试：测试签名模式（本文档）
   - 正式发布：需要 **EV 代码签名证书** + **微软 WHQL 认证**
     否则用户机器无法加载（除非用户自己开测试签名）

4. **UI 集成**
   软件内部打开 `\\.\UmSerialFilter` 并循环 `IOCTL_UM_GET_RECORD`，
   把记录送入现有的会话/视图管线。
